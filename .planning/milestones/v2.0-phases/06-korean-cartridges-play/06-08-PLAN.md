    store site by its target, each target in exactly one family: Sega $FFFC-$FFFF; Korean $A000; Zemina $0001-$0003
    ($0000 is also the Codemasters register, so it counts for neither); 4 PAK $3FFE, $7FFF, $BFFF; Janggun $6000
    ($4000 and $8000 are Codemasters registers and $A000 is Korean's). Comment the targets with their source (MAME
    rom.cpp devices at the pin; SMS-CARTRIDGES section 1.4).

    header); 8 KiB image loaded as Game Gear refused (source default, kept ahead of the header so the cheat device
    stays refused); valid header = magic found, region code 3 to 7, checksum_ok, and the size code's range at most
    the body, giving ROM-only up to 48 KiB else Sega (source header); otherwise up to 48 KiB ROM-only (source
    default); otherwise the scan. A bad-checksum header contributes nothing. Scan rule with T = 3 for every family
    (conservative until measured): F is the family with the most sites (fixed order Korean, Zemina, 4 PAK, Janggun
    breaks ties), x its count, y the runner-up's, s the Sega count. If x is 0: Sega, source default. F wins when
    x >= 3, x >= 2s + 2, x >= 2y + 2, its geometry fits (Korean and 4 PAK whole 16 KiB pages; Zemina whole 8 KiB
