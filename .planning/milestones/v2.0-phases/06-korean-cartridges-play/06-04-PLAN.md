    `switch (m->cart.board)` in read or write. Read's `default:` becomes `return cogmaster__mapext_read(m, addr);`.

    `switch` arm per board, and no function pointer table, giving the reason in words: a PIC pointer table lands in
    .data.rel.ro and abi.globals rejects it (no lesson or planning ID in the comment). For now each function has only
    its `default:` arm and reproduces today's behaviour exactly: cogmaster__mapext_read returns $FF;
    cogmaster__mapext_write records COGMASTER__DEVICE_CART / COGMASTER__FAULT_ROM_WRITE through cogmaster__bus_fault
    for an address below $C000 and does nothing at $FFFC-$FFFF; cogmaster__mapext_reset leaves the zeroed banks.
    Plans 06-06 and 06-07 add the board arms and the shared 8 KiB read; no unused helper goes in now (the build uses
    -Werror). Integer-only, fixed-width types, no allocation (rule 4).
    src/internal.h: add `uint8_t bank8[6]; /* boards 4 and up: the 8 KiB bank in each of $0000-$BFFF's six slots,
    each below twice the page count */` and `uint8_t raw[2]; /* boards 4 and up: register values a board needs to
    recompute a bank */` to struct cogmaster__mapper; append COGMASTER__BOARD_KOREAN, _KOREAN_NB, _HICOM, _ZEMINA,
    _NEMESIS, _4PAK to the internal enum from the public constants; declare the three mapext functions beside the
    mapper ones. Add src/mapper_ext.c to the library sources in CMakeLists.txt.
    src/state.c: set the tripwire to the new sizeof (12). In mapper_io, after the existing bank loop and only when
    `board >= COGMASTER__BOARD_KOREAN`, visit each bank8 entry with cogmaster__sio_u8 bounded 0 to
    (pages != 0 ? 2 * pages - 1 : 0) and each raw entry 0 to 255, under new names `mapper_bank8` and `mapper_raw`.
    Sega and Codemasters states visit exactly the fields they visit today, so their state bytes differ only by the
    format number plan 06-02 bumped.
