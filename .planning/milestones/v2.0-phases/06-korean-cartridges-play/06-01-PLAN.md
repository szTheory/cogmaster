    Implement in tools/cartdb.c, own MIT code (rule 1); no MAME text enters it.

    Slot table (CONTEXT, "Hash table and generator"): one `static const` array of rows `{name, id, board, reason}`.
    Board values come from include/cogmaster.h constants (COGMASTER_BOARD_CODEMASTERS and friends), never literals;
    unsupported is board 0 with a non-empty reason. Add a self-check at start-up that fails (exit 1, "slot table")
    when a row has a non-zero board and a reason, a zero board and no reason, or a duplicate name or id. Stable ids,
    never renumbered: 1 codemasters (CODEMASTERS), 2 eeprom, 3 mgear, 4 xterminator, 5 cardcatcher, 6 castle,
    7 dahjee_typea, 8 dahjee_typeb, 9 level3, 10 othello, 11 terebi, 12 4pak, 13 hicom, 14 janggun, 15 korean,
    16 korean_188in1, 17 korean_nb, 18 nemesis, 19 seojin, 20 zemina; id 0 means the record has no slot feature.
    Reasons (each at most 95 bytes, ASCII, no tab): eeprom "93C46 EEPROM save chip not emulated" (Claude's
    discretion: these rows are board 0 today; keeping them refused avoids a game whose saves silently vanish; the
    saves phase flips the row); mgear "Master Gear converter, not a game"; xterminator "X-Terminator cheat device";
    the seven SG-1000 slots "SG-1000 board; the SG-1000 is not emulated"; janggun "reverse bit 6 vs 7 unresolved
    (MAME and SMS Power disagree)"; korean_188in1 "menu entries 6 and 13 fail in MAME and ares"; seojin "game select
    at $FFF0 and data bit 7 inverted; no hardware dump evidence". Per the CONTEXT wave-1 rule, 4pak, hicom,
    korean, korean_nb, nemesis and zemina are board 0 with reason "mapper arm not present"; plans 06-06 and 06-07
    flip each row when its arm lands, so no row ever names a board without an arm. Remove the dead `rom` and `sega`
    slot branches: those strings are not in the pinned lists, so they now fail as unmapped.

    Parsing: scan every `<feature name="slot">` of every `<software>` before the multipart and compound exclusions,
    so `seen` counts excluded records too; an unmapped slot exits 1 with `cartdb: unmapped slot <name>`. Read
    `<sharedfeat name="ctrl1_default">` and `ctrl2_default` anywhere in the software record into ctrl codes: 0 none,
    1 lphaser, 2 paddle, 3 sports, 4 graphic; any other value exits 1 with `unmapped controller <value>`. A record
    whose slot is `eeprom` gets persistence 3 (EEPROM), overriding the battery default. The declared RAM size must fit
    16 bits or the run exits 1 ("invalid ram size"). Board: the table's board when a slot is present, else the
    current size and battery rules (unchanged). Flags bit 0 is the public identity (commercial rows 1, the owned
    fixture 0). The duplicate check compares slot as well; for ctrl, a device on one alias and none on the other
    keeps the device, and two different devices exit 1 as a conflicting identity.

    Options: `--list-slots` prints each table name, one per line, sorted, and exits 0 without reading input.
    `--catalog PATH` writes one line per emitted public row, tab-separated: 40-hex sha1, machine (`sg`, `sms`, `gg`
    for 0, 1, 2), board name (`unsupported`, `none`, `sega`, `codemasters` for 0 to 3), slot name (`-` for id 0),
    title; a title holding a tab or newline exits 1. `--pin HEX40` is required when writing a table and goes into
    the first output line. stderr gets one line per table slot, sorted by name:
    `cartdb: slot <name> seen=N emitted=M -> <board name or "unsupported (reason)">`, then the existing summary.

    Output (the format plan 06-03 compiles; keep it exact): line 1 is
    `/* Generated by tools/cartdb.c from the MAME hash lists at <pin>; CC0 facts, see PROVENANCE.md. */`. Then
    `static const struct cogmaster__cart_slot cartdb_slots[] = {` with one row per table slot in id order:
    `{<id>u, <board>u, "<name>", "<reason>"},`, and `};`. Then
    `static const struct cogmaster__cart_fact cartdb_facts[] = {` with one designated-initializer row per unique
    SHA-1 in sorted order: `.sha1 = {` 20 bytes each written `0x` plus two lowercase hex digits `}`, then `.bytes`,
    `.ram_bytes`, `.board`, `.slot`, `.machine`, `.region`, `.video`, `.persistence`, `.geometry`, `.ctrl1`,
    `.ctrl2`, `.flags`, each an unsigned decimal with a `u` suffix, and `};`. No title, no string in a fact row, no
    pointer. Hex sort order equals binary order, so keep the qsort on the hex string.

    The --fixture reader keeps its file format and checks; its row gets slot 0, ram_bytes from its declared size and
    flags 0, and it is never written to the catalog.

    In tests/cart/tests.cmake give cogmaster-cartdb the public include directories:
    `target_include_directories(cogmaster-cartdb PRIVATE ${PROJECT_SOURCE_DIR}/include ${PROJECT_BINARY_DIR}/generated)`.
    Write Task 2's generator assertions first and watch them fail, then implement.
