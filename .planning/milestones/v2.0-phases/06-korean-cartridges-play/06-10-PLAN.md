    Write tests/roms/src/mapper_korean.asm, own MIT assembly (rule 1; no third-party bytes), selected by
    `FIXTURE_BOARD` 1 Korean, 2 Zemina, 3 4 PAK. 128 KiB as sixteen 8 KiB banks, each with a start stamp and an end
    stamp (bank number and its complement, a different pair at the end). The start stamp sits at the same bank
    offset in every bank, after the reset ($0000), interrupt ($0038) and NMI ($0066) vectors, for example offset
    $0080; never at address 0, where bank 0 holds its reset code. Bank 0's start pair ($00, $FF) decodes as two
    one-byte instructions, so the sweep stays aligned before the store sites that follow it. No ROM header: do not include
    header.inc, so the board comes from the scan. Header comment lists the records, as mapper_sega.asm does, and
    cites the board facts (MAME rom.cpp devices at 1d7a454ed79e). Records per image: the stamps every slot shows at
    reset; for each register, the stamp a slot shows after a write; the power-of-two wrap (8 KiB boards: value 16 + k
    selects bank k; Korean and 4 PAK: page 8 + k selects page k); for Korean and Zemina, a write of each of
    $FFFC-$FFFF leaves the slots' stamps unchanged; for 4 PAK, a write to $FFFF moves slot 2 to the written page
    (the Sega register MAME's 4 PAK inherits, as plan 06-07 implements and cites). Detection constraints: at least ten LD (nn),A sites to the
    board's own registers in the first 32 KiB, aligned code (no data that desynchronises the sweep before them), and
    no LD (nn),A to another family's target; write $FFFC-$FFFF with LD (HL),A so they are not store sites. Run code
    from work RAM whenever slot 0 can move (4 PAK $3FFE), as mapper_codemasters.asm does. At the end, set the
    backdrop colour from a stamp read through a paged slot and enable the display, so a wrong bank changes the frame.
    Use a distinct ROM id per board in mb_init.
    tests/fixtures/tests.cmake: build the three images like vdp_lines: one generated link file each from
    mapper_korean.link, `wla-z80 -q -D FIXTURE_BOARD=<n>`, outputs mapper_korean.sms, mapper_zemina.sms and
    mapper_hes_4pak.sms, added to fixtures_images. Append three `<name> <sha256>` lines to tests/built/expected.txt

    style of the others.
