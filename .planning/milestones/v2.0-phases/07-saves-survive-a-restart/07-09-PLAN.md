<objective>
Finish the runner's durability (CONTEXT, "Runner durability and the hosted round trip"): a bounded sweep of stale
temporaries with one temporary-name pattern on every platform, a POSIX directory sync after the rename, and
deterministic kill tests through the existing fault points, on top of plan 07-08's periodic flush.

CONTEXT amendment (registration): CONTEXT says the `COGMASTER_SAVE_DIRSYNC` fault test is "registered only where a
directory sync exists (not `_WIN32`, not `__wasi__`)" and that the O_EXCL case is "registered under `if(WIN32)` or
`if(NOT WIN32)`". That wording is superseded for registration: every lane that selects the `ci` inventory (including
ci-msvc on Windows x64 and arm64, and the wasm32 lane for its own inventory) must register exactly the names its
inventory lists, because `cogmaster__check_inventory` is a configure-time FATAL_ERROR and "Every test ran" checks the
junit. So the same test names are registered on every lane; the behaviour each asserts differs per platform, the
registration does not. SKIP_RETURN_CODE stays forbidden.

Purpose: a killed process loses at most N frames of progress and leaves nothing behind that the next run trips on.
Output: sweep, unified names, next-index unit case, dirsync and its fault test, the kill test, inventories, docs.
</objective>
