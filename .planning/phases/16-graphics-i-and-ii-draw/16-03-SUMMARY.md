## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] The multicolour seed cannot spell a zero byte in CMake**
- **Found during:** Task 2 (the first `runner.diagnose` run after the seed edit)
- **Issue:** the plan sets R0 to `$00` by changing the `LD A,n` operand to 0 in `string(ASCII ...)`; CMake refuses it ("Character with code 0 does not exist") and the test failed at configure of the image.
- **Fix:** `XOR A` (byte 175) clears A in one byte, so the image is `DI; XOR A; OUT ($BF),A; LD A,$80; OUT ($BF),A; LD A,$48; OUT ($BF),A; LD A,$81; OUT ($BF),A; HALT`, 17 bytes, and the pad is 1007 bytes; the file stays 1024 bytes and `want_checked 11` is unchanged. The comment says why.
- **Files modified:** `tests/runner/diagnose.cmake`
- **Verification:** `runner.diagnose`, `runner.trace.fault` and `library.diagnose` pass, 3 of 3; the multicolour row reads `vdpmode=multicolor`.
- **Committed in:** `ca35409`
