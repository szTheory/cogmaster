<objective>
Give cogmaster-run a read-only `--diagnose` mode that runs a cartridge for 1800 frames and prints one closed-vocabulary
line of facts, with its frame-600 verdict computed by the same code and state as `--expect boots@600` (D-01, D-02,
D-03, D-04, D-19). This is the per-cart half of DIAG-01; the library half (`library.sh diagnose`) is plans 02 and 03.

Purpose: the failing rows need facts the boots predicate cannot give (first non-blank frame, picture count, an
1800-frame view, the fault class), and those facts must leave the runner already closed: numbers, enum words and
static-table words only.
Output: runner/diag.c and runner/diag.h, the split of runner/expect.c, the `--diagnose` option, test `runner.diagnose`,
docs/runner.md section.

File count (16) is deliberate: the files are the expect split, the diag pair, the args and main wiring, the board-source
table moved out of runner/probe.c (moved, never duplicated), the new test with its registration, the two inventories and
the docs, plus runner/diag_class.h and one case in tests/runner/test_runner.c so the derived fields (fault_frame bucket,
order, pcslot, where) are called with chosen values: no owned fixture faults at frame 599 or 600, CMake cannot write a new
image (13-RESEARCH.md "Test design"), and a header of static inline helpers, the form runner/path.h already uses, lets
the existing cogmaster-test-bench call them with no new link dependency (runner/diag.c would pull in expect.c, probe.c
and their digests). Plan 01 is a single vertical slice, and splitting it would leave a half-wired option that no test can
pin.

Stated deviations from 13-CONTEXT.md, each from new evidence in 13-RESEARCH.md ("CONTEXT Risks and Corrections"),
within the spirit of the locked decisions:
- R3 (fault timing): D-03's fault frame buckets (0, 1-9, 10-99, 100+) cannot tell frame 150 from frame 700 and the core
  keeps one first fault for the whole run (src/fault.c, src/bus.c `f.frame = m->frame`). The line prints the bucket set
  0, 1-9, 10-99, 100-599, 600+ and F at frame 600 is `present && fault.frame < 600`; order uses the 1-based call index
  against the 0-based fault.frame: before when `fault.frame + 1 <= first_nonblank`.
- R5 (first_change): D-07's pass-row histogram needs the frame a passing picture first moves; D-03 lists no such
  field. The line adds `first_change=<n|none>`.
- Address class: D-18's list misses the Codemasters registers at $0000/$4000/$8000 (src/mapper.c), so the class comes
  from (device, addr), and the runner prints `pcslot=0..4` so awk never parses hex (mawk has no strtonum).
- RAM liveness (D-19, Claude's discretion): shipped, because it costs one 8192-byte copy and one memcmp; the comparison
  of a saved copy is the hash comparison D-19 names without collisions.
