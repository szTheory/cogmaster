Core side (D-04, D-06, D-09, D-10): `src/z80.h` declares `struct cogmaster__z80` with `uint8_t r[]` register
file (IXH/IXL/IYH/IYL at fixed indices, alternates, no unions), `pc`, `sp`, `wz`, `i`, `r` (refresh), `iff1`,
`iff2`, `im`, `q`, `p`, `ei`, `idx` (pending prefix), `halted`, `int_line`, `nmi_pending`, and declares
`cogmaster__z80_step(cogmaster *m)` plus the six seam prototypes. `src/z80_cycle.h` holds static inline `m1`,
`mread`, `mwrite`, `ioread`, `iowrite`, `idle(addr, n)` and `setf()` (writes `f` and `q` together): each adds 3
ticks per T-state to `m->ticks` and calls the seam once at the data T-state (M1 and memory read at T3, memory
write stamped at its data T-state per D-10, I/O at the fourth T-state after the automatic wait); `m1` forms the
refresh address from I and R before incrementing R's low 7 bits, keeping bit 7. `src/z80.c` holds the step: save
then clear `q`, clear `p`, dispatch the main page with one `switch` (D-05) — implement `0x00` and `0x02` (WZ per
Sean Young's MEMPTR table) now; every other opcode reaches a default arm the next plans fill. No function-pointer
tables, no loops over prefixes (D-07). `src/internal.h` includes `z80.h` and embeds `struct cogmaster__z80 z80`.

Test side (D-12, D-13): `tests/z80/sst_stream.{h,c}` defines the sample format above and `sst_stream_build`,
which expands an access list plus total T-states into the per-T-state stream using the D-12 templates (M1
`[pc,-,----][pc,-,r-m-][IR,op,----][IR,-,----]`; memory read data at T3; write data at T2 with `-wm-`; I/O
4 T with `r--i`/`-w-i` at T3, read data at T4; idle T-states repeat the previous address with null data and
`----`). `tests/z80/sst2bin.c` (host C tool `cogmaster-sst2bin`, CLI `--dir V1DIR --count N --out FILE` and
`--files NAMES` to restrict) generates the 1,604 names from the closed rule (names contain spaces), tokenizes
the fixed schema (numbers, `null`, short strings, arrays, objects), fails naming the key on a missing key,
skips unknown keys, extracts accesses, rebuilds the stream with `sst_stream_build` and exits 1 naming file and
test if it differs from the JSON `cycles`. `tests/z80/sst_bus.c` defines the six seam functions, logs
`{kind, tick, addr, data, refresh}` and serves memory and ports from the test's lists. `tests/z80/sst_run.c`
(`cogmaster-test-sst`, CLI `--sample FILE [--group base|cb|dd|ddcb|ed|fd|fdcb] [--only NAMES]
[--expect-count N] [--allow FILE] [--corrupt FILE TEST FIELD]`) reads the sample with one `fread` into a heap
buffer, for each test sets the state, restores only the RAM addresses the test lists or the core wrote (never a
64 KiB clear), steps until `idx` is clear (Pitfall 3), compares every final field and the stream rebuilt from
the logged accesses, prints the first differing field or T-state with both values, prints `executed N`, and
exits 1 on any mismatch or when `--expect-count` differs. `tests/z80/tests.cmake` builds both executables from
their sources plus `src/z80.c` (never linking `cogmaster`, Pattern 2) with the core's compile options; include
it from `tests/tests.cmake`.
