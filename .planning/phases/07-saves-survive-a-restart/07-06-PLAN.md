    byte-equal. Cap the input at a fixed number of pairs so every call is bounded. Free everything before returning
    (XFER-079 leak rule).

    "Fault prevented" comments cover it, extended by "or an EEPROM clock stream that leaves the chip out of bounds".
    Inventories: `fuzz.libfuzzer.eeprom	fuzz` in fuzz.txt; `fuzz.regress.eeprom	fuzz,portable` in ci.txt and
    wasm32.txt, sorted. docs/perf-fuzz.md: one line naming the new entry. Negative controls: (1) temporarily skip the
    state load in fuzz_eeprom.c's final comparison so it compares against a zeroed buffer and confirm
    fuzz.regress.eeprom fails; (2) temporarily tighten the per-write bound check to demand count 0 in every phase and
    confirm fuzz.regress.eeprom fails (any replayed seed that clocks a start bit trips it; if none does, say so in the
