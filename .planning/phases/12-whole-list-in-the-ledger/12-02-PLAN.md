## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ledger file to awk parser | titles, evidence and ids are untrusted bytes |
| reasons.txt to parser | a data file read by trusted code decides which statuses parse |
| parser output to page | titles become markdown |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-05 | Tampering | unsupported or skipped row with no checkable reason | high | mitigate | anchored reason pattern plus listed token, exit 2 in every mode; compat.csv controls |
| T-12-06 | Spoofing | bidi, zero-width or formula-leading title | high | mitigate | octal byte regex and first-byte rule; compat.hardening controls under three awks |
